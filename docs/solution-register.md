# Complete solution and attempted-solution register

This register preserves the complete solution history rather than publishing only the mechanisms that survived. `Verified` means the named source records a verification for its tested version and procedure. `Failed`, `regressed`, `reverted`, `superseded`, and `dormant` are equally important outcomes.
